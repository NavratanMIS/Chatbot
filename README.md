# Simple Chatbot Example

This repository contains a minimal rule-based chatbot written in Python. The chatbot answers common customer questions and attempts to detect when a user might be interested in making a purchase.

## Requirements
- Python 3.8+

No additional third-party packages are required.

## Usage
Run the chatbot from your terminal:

```bash
python chatbot.py
```

Type your questions and the bot will respond with canned answers. When the conversation is over, type `quit` to exit.
